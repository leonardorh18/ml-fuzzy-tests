\section{Experimental Setup}\label{sec:setup}

\textbf{Models under test.} We selected three small instruction-tuned chat models from different families, so that differences between them are not artifacts of a shared training pipeline (Table~\ref{tab:models}). All models ran locally with greedy decoding and at most 256 new tokens. We did not use the API client in the experiments because no Hugging Face API token was available in the execution environment.

\textbf{Environment.} A Linux cloud container with 4 CPU cores and 15\,GB of RAM, no GPU, Python 3.13, PyTorch 2.14.1, and \code{transformers} 5.21.0.

\textbf{Main campaign (RQ1, RQ2, RQ4).} The generator produced 60 skeletons, 10 per category, each derived as 3 paraphrases, for 180 prompts per model and 540 model responses in total (grammar seed 0, $b = 0.8$). Every model received the same prompts.

\textbf{Ablation 1: grammar coverage without models (RQ3).} For 30 grammar seeds, we generated 120 prompts with uniform random expansion ($b = 0$) and with coverage-guided expansion ($b = 0.8$), and recorded grammar coverage after each prompt.

\textbf{Ablation 2: failure diversity with models (RQ3).} For grammar seeds 0, 1, and 2 and both values of $b$, we ran 30 skeletons with one wording each on the two faster models, Qwen2.5 and SmolLM2. We compare the number of failures, the number of distinct grammar rules that appear in failing prompts, and the number of distinct failure signatures (model, category, oracle verdict, and top-level template).

\textbf{Oracle validation (RQ4).} We drew a stratified random sample of the main campaign's graded responses, balanced across categories and models, and compared each automatic verdict with a manual judgment of whether the reply answered the request correctly.

\textbf{Metrics.} Pass rate per model and category; number of findings of each type; metamorphic consistency, the share of skeletons for which a model gave the same canonical answer to all paraphrases; pairwise disagreement between models on comparable prompts; consensus-wrong prompts; and grammar coverage.
