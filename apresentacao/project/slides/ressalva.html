Antes dos resultados

Os modelos rodaram com pesos aleatórios

O ambiente bloqueou o Hugging Face. Usamos as arquiteturas reais com pesos aleatórios, 6 imagens sintéticas e um vocabulário local no tokenizer.

Os testes provam que o pipeline funciona. Os números dos classificadores não medem a robustez dos modelos treinados.

Isto é importante para ler o resto da apresentação. O container onde os testes rodaram não conseguia acessar huggingface.co, então nenhum peso treinado foi baixado. O código tem a opção --random-weights, que monta a mesma arquitetura com pesos aleatórios fixos. A lógica do tokenizer é a mesma; só o vocabulário foi trocado por um pequeno criado localmente.
