Models

Two image classifiers and one text tokenizer

ResNet-50

Purpose: identify the object in a photo among the 1,000 ImageNet classes.

How: a 50-layer convolutional network whose filters detect edges, textures and shapes.

photo of a dog
→ "golden retriever"

ViT-Base

Purpose: the same task as ResNet-50, with the same 1,000 classes.

How: splits the photo into 16×16-pixel patches and applies attention, the technique behind language models.

photo of a mug
→ "coffee mug"

Tokenizer

Purpose: split text into pieces (tokens) and map each one to a number that DistilBERT understands.

Why test it: every text passes through it before reaching the model.

"the cat is sleeping"
→ [CLS] the cat is sleeping [SEP]

ResNet and ViT perform the same task with different architectures, so both can be compared on identical images.

All three targets come from Hugging Face. ResNet-50 is a classic convolutional network for recognizing objects in photos. ViT, the Vision Transformer, performs exactly the same task but treats the image as a sequence of small patches, much as a language model treats words. The DistilBERT tokenizer, DistilBERT being a compact version of BERT, turns text into numbers; if it fails, everything downstream receives the wrong input.
