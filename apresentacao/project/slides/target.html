1 · TARGET SOFTWARE AND PROBLEM

Chat models are components, but hard to test

They rarely crash

A crash oracle, the engine of most fuzzers, reveals almost nothing.

Input is natural language

No parser whose structure a fuzzer could exploit.

No single right answer

The test-oracle problem at its most acute.

Systems under test: three small open chat models from the Hugging Face Hub — Qwen2.5-0.5B-Instruct, SmolLM2-360M-Instruct, TinyLlama-1.1B-Chat — run locally with transformers.

The hosted HF API client is implemented but was not used (no access token).

O alvo são modelos de chat abertos do Hugging Face. Eles viram componentes de software, mas três coisas dificultam o teste: quase não travam, a entrada é linguagem natural e quase nunca existe uma única resposta certa. Deixem claro que testamos os modelos rodando localmente, não a API hospedada, porque não havia token.
