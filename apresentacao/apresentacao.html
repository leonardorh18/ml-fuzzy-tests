What is fuzz testing

Feeding a system generated inputs until something breaks

Instead of writing test cases by hand, a program (the fuzzer) generates thousands of inputs automatically and observes how the system behaves.

Classic example

A PDF reader receives thousands of slightly corrupted files. One of them crashes the program: a bug found before a user, or an attacker, finds it.

1. Generate an input

at random, or by mutating an existing one

2. Run the system

and record what it exercised

3. Check: did it fail?

the rule that decides is the oracle

4. Keep it if it explored something new

guided by coverage; repeat thousands of times

How it works · neuron coverage

The fuzzer keeps images that activate new neurons

never activated

already covered

new in this mutant

Illustrative sketch of one layer

Neuron

one channel of a ResNet block or one hidden dimension of a ViT block

Covered

some input has activated it above 50% of the layer's maximum

Feedback

a non-failing mutant that activates new neurons returns to the corpus and spawns new mutants

Idea from DeepXplore (2017) and TensorFuzz (2019)

Models

Two image classifiers and one text tokenizer

ResNet-50

Purpose: identify the object in a photo among the 1,000 ImageNet classes.

How: a 50-layer convolutional network whose filters detect edges, textures and shapes.

photo of a dog
→ "golden retriever"

ViT-Base

Purpose: the same task as ResNet-50, with the same 1,000 classes.

How: splits the photo into 16×16-pixel patches and applies attention, the technique behind language models.

photo of a mug
→ "coffee mug"

Tokenizer

Purpose: split text into pieces (tokens) and map each one to a number that DistilBERT understands.

Why test it: every text passes through it before reaching the model.

"the cat is sleeping"
→ [CLS] the cat is sleeping [SEP]

ResNet and ViT perform the same task with different architectures, so both can be compared on identical images.

Random weights

The environment could not reach the Hugging Face Hub. The models ran with their published architectures and random weights, and the tokenizer with a local vocabulary.

The experiment validates the method; the numbers do not measure the robustness of the trained models.
