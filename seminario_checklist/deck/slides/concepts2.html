Capabilities, perturbations, metamorphic tests

Capability

A skill the task needs

Negation: “not poor” ≠ negative

Perturbation

A controlled input change

Chicago → Dallas

Metamorphic test

Compare outputs, no answer key

Same city swap → same sentiment

Ribeiro et al. (2020), §2; Segura et al. (2016)

Part 2: Three more concepts. A linguistic capability is a skill the task requires, for example understanding negation, named entities, the order of events, or who did what to whom. A perturbation is a controlled change to the input, such as replacing “Chicago” with “Dallas” in a tweet or introducing a typo. A metamorphic test, a technique from software testing, checks a relation between the outputs of related inputs instead of comparing each output with a correct answer. If I only change the city name, the sentiment must stay the same, even if I do not know what the correct sentiment is. This is what allows testing on unlabeled data.
