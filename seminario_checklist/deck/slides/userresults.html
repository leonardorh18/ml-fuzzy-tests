Part 4: The second result concerns the users. In the controlled study, users with the full CheckList created more than twice as many tests as unaided users, 13.5 against 5.8; thanks to templates, each test had 198 cases against 7.3; and they found almost three times as many bugs of severity three or higher, 6.2 against 2.2. An external rater re-scored severity with nearly identical results. In the expert study, the Microsoft team found new, actionable bugs in a mature system and planned to adopt CheckList. A caveat: each group had only six participants and no significance test is reported, so this is a strong indication rather than statistical proof.
