PART 2 · KEY CONCEPTS

From accuracy to behavioral testing

Held-out accuracy

% correct on unseen examples
One number for everything

Behavioral testing

Black box: inputs → outputs
One behavior per test

Like a school report card per subject, not just the final grade.

Ribeiro et al. (2020), §1; Beizer (1995)

Part 2: Thank you. To follow the paper we need a few concepts. The first is held-out accuracy: the percentage of correct predictions on examples the model did not see during training. It is the standard metric, but it summarizes everything in one number; BERT, for example, reaches 92.7% on the SST-2 sentiment benchmark. The second is behavioral testing, also called black-box testing, from software engineering: we test a system only through its inputs and outputs, without looking at its code or weights, and each test checks one behavior. A useful analogy: accuracy is the final grade, while behavioral testing is the report card per subject, which shows that a student with a good average may still fail one subject entirely.
